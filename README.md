## 通用易错点总表（所有题都适用）

- **多组数据没重置变量**：每组数据循环开头把累加器/计数器/标志清零；数组用 memset 或循环重填。
  - 典型题：最长平台 · 田忌赛马 · 超市营业 · 确定进制 · 五子棋判输赢 · 照亮房间 · 习题(15-5) 五户共井问题 · 取石子游戏
- **读入方式与格式不符**：空格分隔用 cin&gt;&gt;；整行（含空格）用 getline 并 ignore 残留换行；逗号分隔读到逗号后 cin.ignore()。
  - 典型题：单词倒排 · 文字排版 · 求交集 · 求亲和数 · 招聘会人数 · 计算书费
- **整数溢出**：int 上限约 2.1×10⁹。连乘、幂、阶乘、大数累加尽早换 long long。
  - 典型题：角谷猜想 · 猴子分苹果 · 最高纪录 · 1118 计算2的N次方
- **浮点精度与输出**：判等用 fabs(a-b)&lt;1e-9；输出 fixed &lt;&lt; setprecision(2)；整数上取整写 (a+b-1)/b。
  - 典型题：骑车与走路 · 缓存命中率 · 海龟去哪儿了 · 计算数据的方差
- **边界与特殊值**：n=0、n=1、空串、只有一个元素、首尾元素——动笔前先想最小用例。
  - 典型题：习题(4-2) 点和正方形的关系 · 超市营业 · 中间值判断
- **下标 0 还是 1**：输出“第几个”时与数组下标差 1；循环边界 &lt;n 还是 &lt;=n 先想清楚。
  - 典型题：位置查找 · 记数问题 · 习题(11-2) 校门外的树
- **输出格式**：行末多余空格、换行、大小写、无解时的输出（Forget it. / not found / NULL / n）。
  - 典型题：计算书费 · 垂直直方图 · 提取数字串按数值排序 · 求交集 · 习题(4-4) 能被3，5，7整除的数 · 房价 vs 年薪 · 计算鞍点
- **数组开多大 & 开在哪**：按题目最大规模 +5 保险；≥10⁶ 的大数组开全局（防栈溢出）。
  - 典型题：统计字母和数字个数 · 垂直直方图
